# Plan 15-02: API Testing Frontend

## Objective

Update the new-run page to allow users to select between "Browser" and "API" run modes, add an `ApiSpecUpload` component where users can paste or upload an OpenAPI JSON spec, extend the `useRunFormStore` to pass `runType` and `apiSpec` to the backend, and add an `ApiTestResults` tab in the run report/live page that displays pass/fail results per endpoint.

**Depends on:** Plan 15-01 (backend must be complete — `runType` field, `api_test_report` type exist)

## Context

- **New run page:** `frontend/app/run/new/page.tsx` — add run type toggle above persona selector
- **Run form store:** `frontend/stores/useRunFormStore.ts` — add `runType`, `apiSpec` fields
- **Frontend API client:** `frontend/lib/api.ts` — extend `CreateRunRequest` with `runType`, `apiSpec`
- **Run live page:** `frontend/app/run/[runId]/live/` — add API Results tab
- **New components:**
  - `frontend/app/components/api-spec-upload.tsx` — textarea + file upload for OpenAPI spec
  - `frontend/app/components/api-test-results.tsx` — table showing per-endpoint results

### Task 2: Extend useRunFormStore

**File:** `frontend/stores/useRunFormStore.ts`

Add to `RunFormStore` interface:
```typescript
runType: 'browser' | 'api';
apiSpec: string;
setRunType: (t: 'browser' | 'api') => void;
setApiSpec: (spec: string) => void;
```

Add to initial state:
```typescript
runType: 'browser',
apiSpec: '',
```

Add setters:
```typescript
setRunType: (runType) => set({ runType }),
setApiSpec: (apiSpec) => set({ apiSpec }),
```

Update `submit` to pass `runType` and `apiSpec` (only if `runType === 'api'`):
```typescript
submit: async () => {
  const { url, personaId, maxSteps, runType, apiSpec } = get();
  const response = await api.createRun({
    url,
    personaId,
    runType,
    ...(runType === 'api' ? { apiSpec } : {}),
    options: { maxSteps },
  });
  return response.runId;
},
```

Update `reset`:
```typescript
reset: () => set({ url: '', personaId: 'new_user', maxSteps: 30, runType: 'browser', apiSpec: '' }),
```

### Task 5: Create ApiTestResults component

Render:
